# 보완 패키지 별도 보관

기존 DB·하네스와 겹치지 않도록 보완 자료만 이 폴더에 저장했습니다.

- 기존 루트 AGENTS.md, MANIFEST.sha256, DB, plugins, 루트 .agents, 설치기와 MCP 설정은 수정하지 않았습니다.
- 이 폴더의 .agents는 저장소 루트에 병합하지 않았습니다. 저장소 루트에서 사용하는 기존 스킬에 자동으로 추가하지 않았습니다.
- fact-grounding 사본은 이 패키지의 휴대용 참고자료이며 기존 정책을 대체하거나 새로 전역 설치한 것이 아닙니다.
- global/AGENTS.md는 exam-kit 안에 있는 복사용 템플릿이며 전역 지침에 적용하지 않았습니다.
- 포함물은 조건부 질문 보완·프롬프트 체계화 스킬, 사실성 지침, 분야별 참고자료, 가상 평가 자료, 환경 검사와 사용 안내입니다. 기존 DB 복제본은 넣지 않았습니다.

## 이 보완 기능을 명시적으로 사용할 때

저장소 루트에서 Codex에 다음처럼 요청합니다.

> supplements/prompt-workflow-kit-20261030/exam-kit/START.md를 읽고 적용해. 다음 요청을 프롬프트로 체계화해줘: …

일반 문제 해결도 같은 START.md를 먼저 지정한 후 문제를 입력할 수 있습니다. 이 요청은 자료 참조 지시이며 설치·전역 설정 변경 지시가 아닙니다.

세부 사용 안내는 exam-kit/README_KO.md, 검증 범위는 exam-kit/VALIDATION_KO.md를 확인하세요. README의 ZIP·루트 병합 안내는 별도의 배포 선택지이며, 현재 보관 상태에는 적용하지 않았습니다.

Python이 없는 환경에서는 지침을 읽어 사용할 수 있지만 DB 명령 실행은 불가능합니다. 별도 PC의 Codex 앱 자동 발견·실제 모델의 준수와 토큰 절감률은 검증하지 않았습니다.
