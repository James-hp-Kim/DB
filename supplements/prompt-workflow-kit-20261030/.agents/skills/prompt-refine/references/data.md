# 데이터분석 — 필요한 항목만 적용
사용자 목적에 맞는 관측 단위, 기간·시간대, 대상·제외 범위, 단위·통화, 분자·분모를 먼저 확정한다. 파일에서 확인 가능한 내용은 묻지 않는다.
열·자료형·행수·기간·결측·중복·조인 키를 먼저 확인한다. 상위 몇 행을 전체 통계로 표현하지 않는다. 전수 처리가 느리면 표본 탐색과 전체 집계를 구분한다.
완전중복과 같은 ID의 다른 사건을 구분하고 제거 기준을 기록한다. 결측을 0으로 바꾸거나 통화를 환산율 없이 합치지 않는다. 분모가 0이면 건수는 보존하고 비율은 산출 불가로 둔다.
가장 단순한 집계·기준모델로 먼저 결과를 만든다. 복잡한 방법은 해결되지 않은 오차나 조건이 있을 때만 선택한다. 시계열은 시간순 분할, 학습 전처리의 누수 방지, 별도 최종 평가를 지킨다. 임의 튜닝 반복을 하지 않는다.
산출물에 적용 범위, 제외·결측 수, 핵심 수치, 계산 또는 재현 경로를 남긴다. 검증은 합계 대사·행수·분모·극단값 등 실제 오류를 찾는 소수 검사로 끝낸다.
예: “매출 분석”은 가능한 기초 집계를 먼저 진행하고, 원인 분석과 예측 중 목적이 결론을 바꾸면 그 선택만 묻는다.
