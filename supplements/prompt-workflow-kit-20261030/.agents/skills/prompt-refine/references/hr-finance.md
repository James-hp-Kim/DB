# HR·재무 — 필요한 항목만 적용
HR 평가는 직무·평가 목적·기간·비교집단·지표 정의를 확인한다. 서로 다른 직무의 단순 수치 순위를 공정성의 증거로 쓰지 않는다. 개인 정보는 필요한 범위만 사용한다.
재무는 통화·단위·회계 기간·대상 조직·매출/이익/현금흐름 구분을 확인한다. 실제와 예산·추정치를 구분하고 합계·비율의 분모를 대사한다. 적용 기준이 중요한 법률·제도는 관할과 기준일을 확인한다.
자료가 없는 개인 평가·비용·효과 수치를 채워 넣지 않는다. 빈 항목은 미확인으로 표시하고 가능한 구조·계산부터 만든다. 필요 없는 인사·규제 요구를 다른 분야에 전파하지 않는다.
