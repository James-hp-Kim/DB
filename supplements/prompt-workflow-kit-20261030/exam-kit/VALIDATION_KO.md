# 배포 검증 결과

- 전역 지침: 본문 149자, 줄바꿈 포함 150자.
- 신규 보완 스킬 2개, 조건부 참고파일 8개, 가상 평가 사례 19개.
- 배포 사본의 고정 로컬 절대경로를 점검했다. 신규 파일은 0건이며 기존 문서의 17개 경로 표기 행도 상대경로·실행 시 경로 계산·기록 비공개 처리로 정리했다. 사용자의 원본은 이 작업에서 변경하지 않았다.
- 다른 경로로 옮긴 사본에서 기존 기능 검사 16개, 페르소나 범위 검사 8개, 새 stdio 연결의 페르소나 9개 검사가 통과했다.
- 위 검사는 등록된 MCP·사용자 스킬·pip·yaml·numpy·pandas·mcp SDK·openai 패키지 없는 임시 환경에서 수행했다. DB 실행에는 Python 자체와 SQLite FTS5가 필요하다.
- Python을 찾을 수 없는 환경도 별도로 모의해 지침 파일 준비 상태는 정상, DB 실행 준비 상태는 불가, DB 필수 옵션은 실패 코드 2로 구분되는 것을 확인했다.
- 패키지 무결성, 참조 링크, 가상 매출 계산, 파일 변조·경로 이탈·파일 충돌 거부를 확인했다.
- 원본에서 발견된 배포 체크섬 불일치는 통합 배포 사본의 manifest를 재생성해 해결했다. 복사된 2.5.1 소스에서 회귀 검사를 다시 수행했다.
- 프롬프트 체계화 기능은 위 핵심 검증 뒤 추가했다. 명시 호출·충분한 입력·체계화 후 실행 사례를 평가 세트에 추가하고 스킬 형식·참조 연결을 검사했다. 실제 모델로 19개 사례를 실행한 것은 아니다.

새 PC의 Codex 앱 자동 인식, 실제 시험 성적, 실행시간 단축률, 토큰 절감률은 미검증이다. 기본 지침을 읽을 수 있다는 검사와 모델이 지침을 준수한다는 검사는 구분한다.
