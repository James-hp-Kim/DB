## procedure

4. 적용 위치를 구분한 블록 구성

Host / FTL주소·내구성 정책→Command queueScheduler / DMA↔ECC engineLLR / retry policy↔NAND PHY명령·DQ/DQS↔NAND die내부제어·page buffer·array

이 도식은 외부 controller에 ECC가 있는 일반적인 개념 모델이며 특정 SK하이닉스 제품의 실제 구조도가 아니다. on-die ECC 또는 내부 test/control 경로를 가진 제품은 소유 블록이 달라진다.

Controller-side RTL: 명령 FSM, target/LUN/plane scheduler, tag·credit 관리, DMA/FIFO, retry policy, ECC datapath, CSR/telemetry가 우선 검토 대상이다. Die-side digital control: 내부 read/program/erase sequence와 analog macro handshake를 다룬다. 후자는 내부 회로 계약·보호 규칙·test mode 정보가 필요하다. Analog/PHY: sense amplifier·charge pump·고전압 회로·DQ/DQS 전기 특성은 RTL simulation만으로 검증되지 않는다.

논문의 AR² 같은 내부 센싱 지연 최적화는 지원된 제어 경로가 있을 때만 후보가 된다. controller가 대기 counter를 임의로 줄이는 것은 동일한 구현이 아니다. P01.
