## procedure

3. RTL 설계자가 알아야 하는 NAND 지식

셀에서 시스템까지

NAND는 셀의 저장 전하에 따른 문턱전압을 판독한다. SLC/2-bit MLC/TLC/QLC는 셀당 각각 1/2/3/4 bit, 이상적인 상태 수로는 2/4/8/16개를 사용한다. 상태 수가 많아지면 분포 사이의 읽기 여유와 측정·정정 정책이 더 중요해진다. 실제 전압 범위와 page별 판독 순서는 제품마다 다르다. S23, P04.

3D NAND의 층 수는 수직 적층 규모이고, 셀당 bit 수와 다른 축이다. NAND의 charge-trap 또는 floating-gate 구조, 층·string 위치·주변 셀 상태는 오류 모델에 영향을 준다. “최신 NAND는 모두 같은 오류 분포”라는 가정으로 모델을 합치지 않는다. 층별·retention별 편차 연구와 QLC cycling 연구가 이 분리를 뒷받침한다. P02, P15.

 | 개념 | 설계에 주는 의미

 | page / block | 읽기·프로그램은 page 관련 단위, erase는 block 단위다. 부분 program 횟수·순서·page mapping은 대상 제품 규정으로 정한다. host 4 KiB와 NAND page 크기를 동일시하지 않는다.

 | channel / target / LUN / plane | 버스 공유와 내부 병렬성의 계층이다. die와 LUN의 대응은 제품 정의를 확인한다. plane 수만 늘려도 공용 버스·전력·명령 제한 때문에 처리량이 비례하지 않을 수 있다.

 | page buffer / cache register | 센싱 결과의 보관과 전송 중첩을 가능하게 하는 자원이다. buffer 수와 명령 제약이 retry pipeline 깊이를 제한한다.

 | ISPP / verify | program pulse와 verify를 반복하는 내부 제어 개념이다. 일반 SSD controller RTL이 내부 고전압 pulse를 자유롭게 정한다는 뜻이 아니다.

 | OOB / parity / metadata | ECC parity·주소/버전·bad block marker 등이 사용하는 부가 영역이다. multi-rate ECC는 공간 배치와 기존 데이터 호환성까지 바꿀 수 있다.

 | FTL / GC / wear leveling | 주소 변환과 블록 관리 정책이다. 주로 firmware/system 범위이며 NAND 명령 제어와 맞물린다. RTL 개선 평가에서도 background traffic을 포함해야 한다.

근거와 추가 읽기: P01 §2, P13 §2, S22, S24. 제품별 geometry·명령 제한은 공개 일반론으로 확정할 수 없다.
