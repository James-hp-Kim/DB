## limits

작성한 연구 요약·설계 제안. 원본 보고서의 PDF 확보 설명은 이전 개인 조사 묶음에 해당하며 이 패키지는 요약과 링크만 포함. 내부 사양·실측 데이터·공정 signoff 기준 없음.

## conditions

제품별 사양과 공개 일반론을 구분한다. 근거 날짜는 2026-10-29이며 최신판 재확인과 독립 재현을 뜻하지 않는다.

## procedure

8. 실제 개선 프로젝트로 옮기는 순서

현재 상태 계측: 요청별 timestamp와 retry index, ECC iteration·syndrome·실패, SRAM/queue stall을 연결한다. 관측값이 없으면 먼저 작은 telemetry를 정의한다.

기준선 동결: 제품·die revision, code·LUT hash, tool·RTL revision, workload·seed·온도·aging을 기록한다. 동일 조건 A/B로 비교한다.

알고리즘 분리 실험: 아래 E01/E03을 먼저 모델에서 검토하고, E02의 지원 기능을 조사한다. 한 번에 여러 기법을 바꾸지 말고 ablation으로 원인을 분리한다.

bit-true와 block 검증: 부동소수 모델 → 고정소수 모델 → RTL을 같은 벡터로 비교한다. reset·backpressure·timeout·실패 fallback을 정상 동작과 같은 비중으로 검증한다.

통합·물리 평가: NAND model/PHY 계약, UVM/formal/CDC/RDC, 합성·LEC·STA·전력, firmware 통합 순으로 결과를 연결한다. 비교 조건이 바뀌면 이득 수치를 다시 측정한다.

실칩 검증과 승인: lot/chip holdout, aging·온도·retention·disturb, tail latency·오검출을 확인한 뒤 사내 기준으로 채택 여부를 결정한다.

제공한 measurement_template.csv는 빈 수집 양식이고, research_data.json은 정리된 문헌 데이터다. 실측값이 들어 있다고 오해하지 않도록 분리했다. 합격 기준이 없는 상태에서는 실험 결과를 PASS로 표시하지 않는다.
