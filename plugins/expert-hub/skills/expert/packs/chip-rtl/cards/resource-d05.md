# Yosys 0.70 Command line reference

ID: `chip-rtl:resource-d05` | both | reference-only

-s는 Yosys script, -c는 Tcl script 입력 — 확장자만으로 언어가 강제되는 것은 아니며 파일 내용과 옵션을 맞춤

## conditions

-s는 Yosys script, -c는 Tcl script 입력

## procedure

주장별 근거 또는 학습 자료

## limits

확장자만으로 언어가 강제되는 것은 아니며 파일 내용과 옵션을 맞춤

## verification

관련 본문 확인; 전체 문헌의 모든 문장 독립 검증 아님. 최초 수집 당시 상태이며 후속 PicoRV32 실험은 chip-rtl:public-benchmark.

## detail

C08: native Yosys 명령 스크립트는 -s를 사용. -c는 Tcl 언어로 작성된 파일일 때 사용.
C21: 저장소 설명과 합성 명령 예제로 확인. 이 컴퓨터 실행 검증과는 별개.
