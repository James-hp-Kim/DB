# Windows 설치와 도구의 역할

ID: `chip-review:installation` | both | reference-only

DB 검색은 Codex·Python/FTS5로 수행하고 EDA·PDK는 필요 작업에 따라 별도로 준비한다.

## conditions

현재 허브의 START_HERE_KO.md 설치 경로를 사용한다. 질문만으로 자동 설치·업로드 권한을 확장하지 않는다.

## procedure

Skill 또는 Plugin 방식 하나를 선택하고 환경 검사 후 페르소나 검색→lookup→read→source를 확인한다. 실제 설계 실험은 필요한 도구/라이브러리 버전부터 확인한다.

## limits

허브 검색에는 외부 API 키·벡터 DB가 필요 없다. 상업 EDA·PDK·모든 도구의 Windows 지원은 별도 조건이다.
