## 요구사항과 baseline
설계 대상이 DRAM 셀인지, 주변 로직인지, NAND 회로인지 먼저 고정한다. 용량, 속도, 전압·온도 범위, 오류율, 보존·수명, 전력 모드, 총면적과 원가 경계를 적는다. 기존 설계의 동일 조건 측정·해석 결과가 baseline이다. 목표값은 제품 규격에서 가져오며 공개 논문 최고값을 임의로 대입하지 않는다.

## 적절한 모델 선택
소자 전계·결함·구조는 TCAD, 회로 전류·센싱·지연은 SPICE, 디지털 동작은 RTL·formal·simulation, 실제 배선 영향은 물리 설계·추출·STA, 메모리 정책은 command 수준 모델, 패키지는 전기·열·기계 해석으로 접근한다. 서로 다른 모델의 입력과 단위가 이어져야 한다.

## 후보 생성과 평가
한 번에 원인을 추적할 수 있는 변경을 만들거나 사전에 설계한 DOE를 사용한다. 기능 검증 후 동일 조건 PPA를 비교한다. 글로벌 공정 코너와 로컬 mismatch를 구분하고, nominal 결과와 worst-case·분포 결과를 함께 기록한다. 최악의 지연 코너와 최악의 누설 코너가 같다고 가정하지 않는다.

## 물리 구현 이후 확인
디지털 주변회로는 RTL 검증, 합성, 논리 동등성, floorplan, 전원망, placement, clock tree, routing, RC 추출, STA, 전력·IR/EM, DRC·LVS 등의 흐름을 따른다. 메모리 custom array와 아날로그 회로는 별도의 소자·회로·레이아웃 검증이 필요하다. [semi-s28, semi-s30]

양의 slack은 해당 제약과 코너의 타이밍 여유다. 0건 DRC는 적용한 rule deck에서 발견된 위반이 없다는 뜻이다. VCD/SAIF 기반 post-route 전력은 활동 정보를 반영한 추정이다. 이 결과만으로 최종 signoff, 테이프아웃, 제조 성공, 실리콘 실측을 선언하지 않는다.

검증 산출물에는 설계 버전, 도구 버전, 모델 버전, 조건, trace, 검사 범위, 예외와 미해결 항목이 남아 있어야 한다. 최종 채택 판단은 해당 조직의 승인된 기준으로 수행한다.
