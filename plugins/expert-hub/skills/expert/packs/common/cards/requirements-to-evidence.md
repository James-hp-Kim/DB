# 요구사항과 검증 증거 연결

ID: `common:requirements-to-evidence` | both | reference-only; no external tool installed

필수 결과를 구현과 독립적인 기대값에 연결하고 통과·실패·미실행을 구분한다. 사용자 확인이나 빌드 성공을 전체 동작 증거로 확대하지 않는다.

## conditions

입력·출력·업무 규칙·필수 파일·완료 기준을 실제 요청과 제공 자료에서 확인한다. 공개 예시의 기술 선택이나 별도 참가 안내 해석을 현재 과제의 규칙으로 바꾸지 않는다.

## procedure

결과를 바꿀 미확정 요구만 확인하고, 이미 합의한 기준은 재사용한다. 필수 경로에 정상·경계·실패 사례를 연결한다. 기대값은 구현 출력과 독립적으로 정하고 관찰 결과·확인 주체·한계를 남긴다.

## verification

실제 관찰한 경우만 통과로 쓴다. 실패와 미실행을 구분한다. 변경으로 영향받은 검사만 갱신하며 파일 생성·형식 검사·빌드·실제 연동·앱 활성화를 각각 판정한다.

## limits

AI 검토나 사용자 동의는 실행 증거가 아니다. 준비 완료는 제출 접수가 아니다. 공식 규정·제출 자동화·하네스 운영은 이 레코드 범위 밖이다.
