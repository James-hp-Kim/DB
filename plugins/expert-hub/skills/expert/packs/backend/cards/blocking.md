# 잠금·장기 트랜잭션 진단

ID: `backend:blocking` | both | reference-only

차단 체인과 트랜잭션 소유·업무 중요도를 확인한다. 시간 기준만으로 세션을 종료하지 않는다.

## conditions

대기/차단 세션, 트랜잭션 상태, 관련 업무, 롤백 비용과 권한이 필요하다.

## procedure

특정 쿼리 취소로 영향을 줄일 수 있는지 판단한다. 세션 종료가 필요하면 정확한 대상·데이터 영향·복구비용을 확인한다. 영구수정은 트랜잭션 범위·락 순서·인덱스·경쟁 접근을 검증한다.

## limits

오래된 세션 일괄 종료나 임의 쿼리 나이 기준은 사용하지 않는다.
