# Is / Is Not으로 문제 범위 축소

ID: `quality:is-is-not` | quick | reference-only

발생한 대상과 비슷하지만 발생하지 않은 대상을 비교해 조사 범위를 좁힌다.

## procedure

문제 특성, 대상, 위치, 최초/최근 발생시점, 규모, 변화점을 같은 표에 둔다.

## interpretation

발생하지 않았다는 판단에는 검사 여부와 관측량이 있어야 한다. 미검사·누락 자료는 정상 대조군이 아니다.
결과는 문제 문장 1개, 영향을 받은 범위, 확인된 정상 비교 범위, 아직 모르는 범위로 요약한다.

## verification

차이를 설명하는 후보를 만든 뒤 반례를 확인한다. 문제 경계가 불명확하면 빠른 원인 확정 대신 필요한 비교자료를 제시한다.
