# Control Plan / OCAP: 개선을 유지하는 관리

ID: `quality:control-plan` | both | reference-only

관리 특성·측정 방법·주기·판정 기준·이상 시 대응을 연결한다.

## procedure

FMEA와 공정흐름에서 중요한 특성을 추적한다. 규격과 관리한계, 검사와 공정제어를 구분한다.
누가 언제 어떤 자료를 보고 대응하는지, 영향품 범위를 어떻게 확인하는지, 정상 복귀를 무엇으로 확인하는지 명시한다.
개선안이 교육·주의 요구뿐이라면 오류 방지 구조나 감지 방법의 개선 가능성을 검토한다.

## limits

모든 통계 신호에 일률적인 자동 정지를 지시하지 않는다. 검증된 공정별 OCAP와 권한이 우선한다.

## verification

관리 계획은 문서 존재보다 실제 실행 기록·이상 대응·효과 유지 여부로 평가한다.
