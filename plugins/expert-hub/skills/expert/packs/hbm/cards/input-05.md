# HBM 입력자료 — 결함

ID: `hbm:input-05` | both | reference-only; no production signoff or physics solver

결함 자료 1개 필드. 단위·정의·계측/설계 출처를 함께 받는다.

## conditions

입력값은 사용자 원본과 적용 revision에서 확보. 모르면 미확인으로 남김.

## procedure

DF15 void_fraction / location / size | 단위: %; µm | 정의: 검사 ROI 분모와 최소검출크기 | 확보: C-SAM/X-ray/단면 | 이유: void 위치가 열경로에 미치는 영향

## limits
