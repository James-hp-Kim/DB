# 책임 경계

ID: `rtl:g04` | both | 참고 지침; EDA 실행·제품 검증 없음

DRAM core/peripheral, HBM base die, host controller, PHY/package의 책임은 제품마다 다르다. 호스트 스케줄러 연구를 DRAM 내부 RTL에 그대로 옮기지 않는다. RTL 기능 검증과 I/O·SI/PI·열·TSV 검증의 책임을 나눈다.

## conditions

기존 DRAM·HBM 공개 연구 자료집의 적용 범위를 판단할 때 사용한다.

## interpretation

DRAM core/peripheral, HBM base die, host controller, PHY/package의 책임은 제품마다 다르다. 호스트 스케줄러 연구를 DRAM 내부 RTL에 그대로 옮기지 않는다. RTL 기능 검증과 I/O·SI/PI·열·TSV 검증의 책임을 나눈다.

## limits

공개 자료 기반 검토용. 대상 제품의 승인 규격·PDK·VIP·사내 승인 기준을 확인해야 하며 제품 통과 판정이 아니다.
