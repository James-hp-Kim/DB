# 공개 전력 데이터의 적용 한계

ID: `rtl:g05` | both | 참고 지침; EDA 실행·제품 검증 없음

Ayna 자료는 36 HBM2 stack/18 U55C, 주로 1200 MT/s SID0 조건이다. 제조사는 확정하지 못했다. HBM3E는 H200 3개 측정, HBM4는 모델 투영이다. total_power_W는 논문의 메모리 전력 계측 맥락이며 전체 GPU 보드 TDP가 아니다.

## conditions

기존 DRAM·HBM 공개 연구 자료집의 적용 범위를 판단할 때 사용한다.

## interpretation

Ayna 자료는 36 HBM2 stack/18 U55C, 주로 1200 MT/s SID0 조건이다. 제조사는 확정하지 못했다. HBM3E는 H200 3개 측정, HBM4는 모델 투영이다. total_power_W는 논문의 메모리 전력 계측 맥락이며 전체 GPU 보드 TDP가 아니다.

## limits

공개 자료 기반 검토용. 대상 제품의 승인 규격·PDK·VIP·사내 승인 기준을 확인해야 하며 제품 통과 판정이 아니다.
