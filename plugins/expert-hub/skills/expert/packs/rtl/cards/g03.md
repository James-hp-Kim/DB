# JEDEC 원문과 숫자 질문

ID: `rtl:g03` | both | 참고 지침; EDA 실행·제품 검증 없음

JEDEC 원문은 확보하지 못했다. HBM4/DDR5의 tRCD/tRFC, 전압, MR bit, speed bin과 mode별 수치를 확정하지 않는다. 모델 지원은 규격 준수 인증이 아니며 승인된 원문과 제품 spec을 연결한다.

## conditions

기존 DRAM·HBM 공개 연구 자료집의 적용 범위를 판단할 때 사용한다.

## interpretation

JEDEC 원문은 확보하지 못했다. HBM4/DDR5의 tRCD/tRFC, 전압, MR bit, speed bin과 mode별 수치를 확정하지 않는다. 모델 지원은 규격 준수 인증이 아니며 승인된 원문과 제품 spec을 연결한다.

## limits

공개 자료 기반 검토용. 대상 제품의 승인 규격·PDK·VIP·사내 승인 기준을 확인해야 하며 제품 통과 판정이 아니다.
