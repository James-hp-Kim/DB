# 전력·에너지 연구

ID: `rtl:f09` | both | 참고 지침; EDA 실행·제품 검증 없음

입력: command/data trace, 전류/전압 모델 → energy, average power, model error / activity 기반 추정과 실리콘 실측 구분

## conditions

activity 기반 추정과 실리콘 실측 구분

## procedure

입력: command/data trace, 전류/전압 모델
