# 반도체 답변의 근거 연결

반도체 전문가·반도체 AI 스킬 전문가 요청에는 계산 문제도 이 절차를 적용한다. 일반 산술·번역에는 적용하지 않는다. DB는 보조 근거이며, 관련 자료가 없으면 외부 검증·계산으로 계속 답한다.

## 주제에 맞는 범위

catalog가 반환한 allowed_packs 안에서 주제에 맞는 팩을 명시한다. 기본 chip-review만 조회하고 반도체 자료가 없다고 판단하지 않는다.

| 질문 | 우선 조회할 팩 |
|---|---|
| 밴드·도핑·pn 접합·MOS·C–V·수송·누설 | semiconductor |
| SRAM 셀·회로 | chip-memory 또는 semiconductor |
| NAND 프로그램·retention·ECC | nand |
| HBM 적층·열·패키징 | hbm |
| CDC·STA·RTL | chip-rtl 또는 rtl |
| 웨이퍼 AI·데이터 누출·학습/평가 분리 | common의 데이터 계약·평가 원칙; 필요 시 quality |
| 칩 설계 검토·하드웨어 검증 계획 | chip-review |

허용되지 않은 팩이면 맞는 페르소나를 catalog로 다시 선택한다. 같은 역할의 허용 팩을 선택할 수 있으면 불필요하게 역할을 바꾸지 않는다.

## 조회에서 답변까지

1. 핵심 용어 2~4개로 lookup한다. 무관한 결과만 있으면 용어를 좁히거나 한글·영문 동의어로 한 번 더 조회한다. 세부 대상명만 반복하지 말고 문제의 목적과 맞는 허용 팩을 선택한다. 예를 들어 웨이퍼 이미지 모델의 검증 질문은 common에서 `데이터 누출` 또는 `평가`를 검색한다. 공통 평가 지침은 평가 설계만 뒷받침하며 웨이퍼 특화 성능을 입증하지 않는다. 검색 순위가 높아도 질문과 무관한 학습 계획·직무 안내를 기술 근거로 인용하지 않는다.
2. 관련 결과가 있으면 요약만으로 끝내지 않는다. 반환된 sections를 보고 실제 설명이 있는 detail 또는 procedure와 conditions·limits를 read한다. 한 번에 ID 1개, 절 최대 3개로 시작한다. present=false나 next_offset을 확인하고 결론에 필요한 누락 부분만 이어 읽는다.
3. read가 반환한 sources 배열의 **출처 ID**를 source에 전달한다. `pack:record-id`는 본문 ID이므로 source 인수로 쓰지 않는다. lookup/read/source에 같은 context와 같은 명시적 packs를 사용한다. 오류나 omitted_ids가 있으면 해당 근거를 확인 완료로 표시하지 않는다.
4. DB를 사용한 문장 바로 뒤에 `[DB: 실제 본문 ID / 출처: 실제 출처 ID]`를 붙인다. 실제 반환된 ID만 사용한다. 출처 URL·검토일·제약을 확인하고 필요하면 해당 링크를 함께 적는다. source는 출처 메타데이터 조회이며 외부 원문을 오늘 열었다는 뜻이 아니다.
5. DB가 일반 원리만 뒷받침하면 그 범위만 인용한다. DB에 없는 식·수치·상세 설계는 **추가 설명·계산**으로 표시하고 필요한 공식 원문을 확인한다. 직접 계산은 입력·단위·가정을 보인다. DB 검색 실패를 전체 지식의 부재로 확대하지 않는다.
6. 관련 본문이 끝내 없으면 `DB 확인 범위: 조회한 팩·용어, 관련 근거 미확보`라고 짧게 쓴다. 무관한 ID를 붙여 조회율을 높이지 않는다. 유용한 외부 근거·설명은 계속 제공한다.

## 한국어와 용어 확인

- 한국어 요청의 설명문은 한국어로 쓴다. 식·영문 약어·고유명사·출처 제목은 보존한다. 최종 답변 전에 도입부·결론·표의 중국어 문장 혼입을 확인하고 한국어로 고친다. 사용자가 요청한 번역·원문 인용은 예외다.
- MOS C–V에서는 **최대 공핍폭에서의 공핍용량**을 쓴다. 면적당 용량은 `Cdep/A = εs/Wdep`이므로 공핍폭 증가와 용량 증가를 혼동하지 않는다. 최대 공핍폭을 뜻하는 `max`를 용량의 최댓값이라고 설명하지 않는다.
- 고주파 반전에서 AC 반전 전하의 응답 제한과 DC 반전층의 존재를 구분한다. 깊은 공핍은 별도 조건이다. [TU Wien, §5.2.1](https://www.iue.tuwien.ac.at/phd/stampfer/node-Capacitance-Voltage-Measurements.html)
- 간단한 SRAM 설명은 저장소를 **교차결합 인버터의 쌍안정 래치**로 표현한다. 일반적인 에지 동작 플립플롭과 동일시하지 않는다.

이 절차는 모델 행동 지침이다. 모든 미래 답변의 완전성이나 기술 정확성을 보증하는 실행 차단 장치는 아니다.
