# 짧은 시험 작업 기록

문제마다 필요한 항목만 사용한다. 사용자 원본과 산출물은 공개 지식 저장소 밖 작업 폴더에 둔다.

- 목표/제출: 해결할 문제, 제출 형식, 종료 시각, 필수 성공 기준.
- 입력 계약: 파일·열·집계 단위·기간·분모·중복/결측 규칙. 표본 확인이면 범위를 표시.
- 기준 결과: 가장 단순한 유효 결과와 비교 지표. 시계열은 시간순, 반복 개체는 그룹 분리. 최종 평가 자료를 개선에 재사용하지 않음.
- 개선: 근거가 있는 변경 하나부터, 시간/반복 상한을 정함. 장애라면 임시조치와 영구수정, 중단/롤백 조건 및 이미 발생한 업무 영향을 구분.
- 확인: 허용된 범위의 비교 가능한 입력·부하·기간, 정확성·효과·부작용. 미실행/실패도 보존.
- 제출: 결론, 핵심 수치와 분모, 근거 위치, 재현 입력/조건, 한계. 대량 행과 반복 결과는 파일로 보존.

동작 검증 금지 요청에서는 기준 결과나 개선 효과를 새로 계산하지 않는다. 계산·검증 계획과 미실행 상태만 기록한다. 문자 제한은 전체 토큰 절감률 보장이 아니다.
