# 적용 및 검증 결과 — 2.5.0 / 2026-10-30

DB와 현재 설치된 expert Skill을 갱신했습니다.
현재 채팅의 기존 MCP 연결은 이전 코드를 유지하고 있습니다. 앱의 서버 재시작은 아직 확인하지 못했습니다.

## 반영한 내용

- 지식 항목: 764개 → 768개. 신규 4개, 기존 4개 보완.
- 출처 레코드: 312개 → 323개. 선택 기술 문서 11개를 추가했습니다.
- 선택 방법: 10개 이름, 9개 실행 절차. Grill Me는 Grilling의 별칭입니다.
- 모든 페르소나에 같은 fact-grounding 안내와 선택 기능 동의 원칙을 연결했습니다.
- Windows용 Setup-NewPC.cmd와 설치 안내를 추가했습니다.

선택 원본을 전부 설치하지 않았습니다. 허브에 필요한 축약 절차를 반영했습니다.
복잡한 문제 전용 방법은 사용자 표현과 사용 동의가 모두 필요합니다.
동의 플래그는 호출자의 선언입니다. 사람이 실제로 동의했음을 인증하는 장치는 아닙니다.

## 남은 앱 재연결

앱의 **Settings → MCP servers → expert-knowledge → Restart**를 실행해야 합니다.
제공된 관리 도구와 `codex mcp`에는 현재 채팅의 서버 재시작 명령이 없습니다.
설정을 삭제하거나 앱 전체를 강제 종료하지 않았습니다.
재시작 후 catalog 응답에 `fact_grounding`과 선택 기능 안내가 포함되는지 확인합니다.
공식 절차: [MCP 설정 안내](https://learn.chatgpt.com/docs/extend/mcp?surface=cli).

## 새 PC 검사 한계

별도 폴더와 비어 있는 Codex 설정으로 검사했습니다.
호스트의 Python과 Codex CLI는 재사용했습니다.
다른 물리 PC, 새 운영체제, macOS, Linux는 시험하지 않았습니다.
Python 설치와 Codex 로그인은 새 PC에서 사용자가 수행해야 합니다.

## 비용과 설명 방식

전체 방법 본문은 기본 입력에 넣지 않습니다. 필요할 때 동의받은 한 방법만 읽습니다.
MCP 도구 수는 기존 5개를 유지했습니다. 별도 선택 도구 10개를 항상 등록하지 않습니다.
문자 수 상한과 토큰 사용량은 다릅니다. 절감률은 측정하지 않았습니다.

설명에는 ASD-STE100의 짧은 문장·한 단계 한 동작·일관된 용어 원칙을 느슨하게 적용했습니다.
‘80%’는 사용자가 요청한 강도입니다. 공식 규격 준수율이나 인증을 뜻하지 않습니다.
