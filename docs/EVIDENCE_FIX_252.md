# 2.5.2 반도체 근거 연결 수정·재검증

검증일: 2026-10-31 · 모델: gpt-6.1-sol · 추론 설정: low

## 수정

- 반도체 페르소나 질문은 해당 주제의 허용 팩을 선택하고 관련 본문·출처를 확인하도록 연결했다.
- semiconductor-ai의 허용 범위에 기존 hbm 팩을 추가했다. catalog가 allowed_packs를 반환한다. 다른 역할의 범위 제한은 유지했다.
- summary만 읽고 끝내지 않고 detail/procedure 등 실제 설명을 읽도록 했다. source에는 본문 ID 대신 반환된 출처 ID를 전달하고 packs/context를 유지한다.
- 사용한 DB 내용은 실제 본문 ID와 출처 ID를 문장에 연결한다. 직접적인 근거가 없으면 공백을 밝히고 외부 자료·계산으로 보완한다.
- 한국어 설명의 중국어 혼입 확인, 최대 공핍폭에서의 공핍용량 표현, SRAM 래치 표현을 추가했다.
- 기본 DB 정본·출처·SQLite 내용은 변경하지 않았다. 기존 문제의 정답을 DB에 추가해서 점수를 높이지 않았다. 2.5.2에 지침·조회 안내 수정으로 적용했다.

## 실제 재시험

- 기존 반도체 10문제를 두 페르소나에 각각 입력했다. 정답·기대 ID·조회 명령을 질문에 넣지 않았다. 질문별 새 설정에서 총 20개 답변을 생성했다.
- 첫 재시험의 웨이퍼 AI 두 답변(F10_AI/SE)은 대상명 반복 검색으로 공통 평가 근거를 놓쳤다. common 팩의 데이터 계약·평가 개념으로 연결하는 안내를 수정해 G10_AI/SE로 재시험했다. 아래 20개 집계는 나머지 18개와 최종 G10 두 개이며, 최초 F10 기록도 별도로 보존한다.
- START.md와 반도체 근거 연결 지침 읽기: 20/20. DB 본문 읽기: 15/20. 출처 조회: 15/20.
- 실제 읽은 본문·출처와 연결된 최종 인용: 14/20. 직접 근거가 부족하다고 밝히고 외부 자료·계산으로 답한 경우: 6/20.
- 직접 근거 부족 사례: F02_AI, F02_SE, F03_AI, F03_SE, F05_AI, F05_SE. pn 접합 계산·아인슈타인 관계·SRAM 강도비 설명이 해당한다. 일부는 조회한 도구 안내 본문을 검토한 뒤 기술 근거로 부적절해 인용하지 않았다.
- 읽지 않은 본문 ID를 인용한 사례: 0. 인용한 DB ID의 연결은 반환된 본문 sources와 실제 source 조회 결과를 대조했다. 이 대조는 모든 기술 문장에 대한 독립 전문가 심사를 뜻하지 않는다.
- 한국어 답변에서 의도하지 않은 중국어 문장 혼입은 관찰하지 못했다. 두 MOS C–V 답변에서 최대 공핍폭과 공핍용량의 관계를 올바르게 구분했다.
- MCP·Plugin 각각 별도 질문에서 모델의 catalog→lookup→read→source 호출 및 최종 ID 연결을 확인했다. 등록 목록만 확인한 결과가 아니다.
- 범위·조회·프로토콜 회귀 검사 26개와 격리 Windows 설치 검사 9개 통과. 전체 저장소의 모든 선택 기능을 다시 시험한 것은 아니다.

## 배포와 제한

- GitHub 대상은 James-hp-Kim/DB이다. 원래 OneDrive 폴더와 기존 전역 설정을 직접 수정하지 않고 배포 사본에서 작업했다.
- GitHub 업로드의 최종 커밋 및 원격 파일 대조 결과는 별도 배포 영수증에 기록한다. 이 문서 자체만으로 업로드 성공을 주장하지 않는다.
- 기존 Windows의 Python·Node·Git·Codex와 현재 계정 로그인을 사용하고 CODEX_HOME을 분리했다. 실제 Windows 신규 설치·새 계정 로그인·다른 PC는 미검증이다.
- 시험 실행은 승인 대기 없는 전체 실행 허용 설정을 사용했다. 사용자의 기본 승인 설정이나 조직 정책에서도 같은 결과를 보증하지 않는다.
- 같은 질문을 수정 전후 반복한 회귀 검증이다. 보지 못한 질문 전체에 대한 정확도나 미래 모든 답변의 완전한 준수 보증이 아니다.
- source 응답은 저장된 URL·검토일·제약 등의 메타데이터다. 외부 원문을 실제로 열었는지는 각 답변의 별도 웹 호출 기록으로 구분한다.
- 최초 자동 지침 연결과 일반 20개·구체화 12개 결과는 이전 검증 기록이다. 이번에는 반도체 20개와 MCP·Plugin 경로를 재시험했다.

## 빠른 시작

```powershell
git clone https://github.com/James-hp-Kim/DB.git
Set-Location DB
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Exam.ps1
```

- 저장소 밖에서도 연결하려면 AUTO_START_KO.md에 따라 Install-Instructions.ps1을 실행한다. 다른 기존 AGENTS.md는 덮어쓰지 않는다.
- GitHub URL만 입력하는 것은 다운로드·전역 지침 설치가 아니다. 전체 저장소와 상대 경로를 유지한다.
