# 데이터 분석 확장 검증 — 2026-10-30

Windows, Python 3.13에서 새 데이터 분석·매출 기능을 검증했습니다. 검증 중 공유 폴더에 다른 분야 작업이 동시에 반영되어, 아래 최초 검증은 기존 공통/품질+analytics/sales만 포함한 고정 사본(66개 레코드, 41개 출처, 3개 역할)을 대상으로 했습니다. 통합 배포본의 개수·검증은 별도 통합 기록을 확인하세요.

|검사|결과|
|---|---|
|데이터 분석 전용|9개 통과: 역할/범위, 예상 검색, 조건·한계, 출처 연결, CSV 프로파일, 부분 스캔, 카디널리티 상한, 잘못된 입력, CLI|
|기존 허브 회귀|16개 통과|
|페르소나 조회 경계|8개 통과|
|백테스트|13개 통과, Ridge 포함(scikit-learn 1.9.1 환경)|
|MCP SDK|실제 stdio에서 초기화, 도구 목록, 역할 검색, 조회·절·출처 연결 통과(MCP SDK 1.30.0)|

합계 46개 unittest 통과와 MCP 프로토콜 검증입니다. 실제 Codex 대화에서의 자동 역할 선택, 실제 회사 매출 성능, GPU 학습, 분산 처리 성능은 검증하지 않았습니다. 설치된 앱의 실제 활성화 여부와 이 코드 검사는 구분합니다.

## 최종 합본 입력 자료량 비교

[data-analysis-benchmark.json](data-analysis-benchmark.json)은 2.4.0 합본에서 다시 측정한 o200k_base 참조 토큰입니다. data-analyst가 허용하는 67개 카드만 전체 로딩 비교 기준에 포함했습니다. 초기 66개 사본의 측정과 구분합니다.

| 방식 | 참조 토큰 |
|---|---:|
|스킬+프로파일+허용된 전체 67개 카드|23,409|
|백테스트 선택 조회+출처|2,000|
|WAPE 분모 선택 조회+출처|1,900|

4개 고정 질문의 기대 항목이 상위 3개에 있음을 확인했고, 선택 본문과 출처가 잘리지 않았는지도 확인했습니다. 역할 검색·스킬·CSV 프로파일·요약·선택 절·출처가 포함됩니다. 실제 과금·추론·답변·도구 정의·대화 이력은 제외합니다. 최종 전체 검증은 [통합 기록](INTEGRATED_VALIDATION.md)을 보세요.

## 한계

- 프로파일은 기본 파일 선두 100000행이며 랜덤 표본이 아닙니다. 최대 30열과 값 종류 최대 256개 해시만 보관합니다. 부족한 부분은 명시합니다.
- 동봉 예측 실행기는 메모리 안에서 처리하는 작은 참조 구현입니다. 분산 빅데이터 실행기는 아닙니다.
- 학습 가중치 자체를 DB에 저장하지 않습니다. 알고리즘·개선 절차·조건·출처를 저장합니다.
- 딥러닝·외생변수·계층 조정·예측구간은 지침이며 연결 코드는 미포함입니다.
- 원출처 재검토는 새 분석 팩의 지정한 공식 기술 자료에 한정합니다. 다른 팩의 모든 원문을 이번 작업에서 재검증하지 않았습니다.
