# 2.4.2 — 공개 준비 지침 선별 반영과 사실성 지침 연결

2026-10-30. 사용자 요청에 따라 공개 GitHub 조사 결과 중 기존 DB에 없는 일반 방법을 선별했습니다. 공식 대회 규정이나 실제 대회 사용 도구 목록을 가져온 것이 아닙니다.

## 지식 변경

지식팩 13개·페르소나 9개를 유지하면서 **760 → 764항목, 출처 레코드 305 → 312개**로 갱신했습니다. 출처 레코드 수는 독립 검증이나 실사용 사례의 수가 아닙니다.

| 구분 | 반영한 내용 | 위치 |
|---|---|---|
| 추가 | 요구사항과 검증 증거 연결 | common:requirements-to-evidence |
| 추가 | 사용 환경에 맞는 결과물·기술 선택 | common:delivery-environment |
| 추가 | 버그 최소 재현과 원인 검사 | backend:minimal-reproduction |
| 추가 | 동작 보존을 기준으로 코드 단순화 | backend:behavior-preserving-refactor |
| 보강 | 결과를 바꿀 데이터 의미만 추가 확인 | common:data-contract |
| 보강·정정 | 선언·설치·실사용 구분, 현재 MCP 도구 5개 | common:skill-mcp-plugin |
| 보강 | 의미·단위·부정어·불확실성을 보존하는 간결한 보고 | common:review-output |
| 보강 | 통과·실패·미실행 및 변경 후 재검증 | common:evaluation-plan |

새 자료의 정확한 공개 URL·고정 버전·본문 SHA-256과 선별 범위는 [변경·검증 기록](UPDATE_242.json)에 보존했습니다. 전체 원문을 복제하거나 외부 설치 프로그램을 실행하지 않았습니다. 데이터 분석의 누수·기준선·조인 규칙처럼 이미 충분히 포함된 내용, 실행 필요성이 확인되지 않은 MCP·플러그인 목록, 검토가 끝나지 않은 참고 스킬, 개인 기록·하네스 운영 정보는 제외했습니다.

## 모든 페르소나의 fact-grounding 연결

이전 설치본에는 일부 사실성 원칙이 있었으나 fact-grounding을 읽도록 하는 명시적 연결은 없었습니다. 이제 다음 경로에 공통 연결을 추가했습니다.

- `expert/SKILL.md`: 페르소나와 관계없이 사실 조사·분석·비교·실행 보고에 fact-grounding을 적용하도록 안내합니다.
- `catalog`: 설치된 원본 지침의 경로·해시·출처 유형·읽기 지시를 반환합니다. 설치 원본이 없거나 읽을 수 없으면 동봉 사본을 명시하여 사용합니다.
- `lookup`과 MCP 초기 안내: 해당 지침을 현재 작업에서 읽고 적용하도록 다시 연결합니다. 이미 읽은 유효한 버전은 재사용합니다.

정책은 9개 역할 설명에 중복 복사하지 않고 공통 코드에서 반환합니다. 원본 fact-grounding 스킬이나 전역 Codex 설정은 수정하지 않았습니다. 현재 설치본의 별도 검색 개선과 한글 출력·출처 ID 안내도 보존했습니다.

**지침 경로·해시 반환은 모델이 실제로 읽고 준수했다는 증거가 아닙니다.** 이번 검증 범위는 지침 연결, 실제 CLI/MCP 응답, 범위 제한 조회와 데이터 무결성입니다. 답변의 사실성이나 자동 스킬 선택을 보장하지 않습니다.

## 기존 연결과 새 연결

설치본을 새 프로세스로 실행했을 때 9개 역할 모두 설치된 fact-grounding 경로와 현재 해시를 반환하는 것을 확인했습니다. 이 채팅에 이미 연결된 MCP는 이전 코드를 메모리에 유지하여 새 정책 필드를 반환하지 않았습니다. 다만 갱신한 DB의 새 지식은 기존 연결에서도 조회되었습니다.

기존 연결의 새 지침 반영에는 MCP 재연결이 필요합니다. 새 채팅에서도 페르소나 검색 결과에 `fact_grounding`이 나오는지 확인하면 적용 경로를 검증할 수 있습니다. 이 채팅에서 다른 MCP나 프로세스를 강제 종료하지 않았습니다.

## 검증과 복구

검사별 실제 결과와 원본 백업 위치는 [변경·검증 기록](UPDATE_242.json)을 참고하세요. 원본 정본과 수정 전 설치 파일은 별도 백업했습니다. 이전 배포·시험 기록은 당시 결과로 보존하며 이번 버전의 성능 증거로 재표현하지 않았습니다. 원격 게시·예약 변경·실사용 환경의 새 플러그인 설치는 수행하지 않았습니다. Windows 설치 검사는 별도 CODEX_HOME에서만 Skill/MCP/Plugin 설치·기존 대상 덮어쓰기 거부 등 9개를 확인했습니다.

검증 결과: 공통 16개, 범위 제한 8개, 사실성 연결 5개, 전체 페르소나·입력 경로 2개로 총 31개 단위/통합 검사가 통과했습니다. 별도 Windows 설치 9개, 공식 MCP SDK 연결, 원본·설치본 스킬 형식 검사, 문서 링크·스냅샷 해시 검사도 통과했습니다. 설치본 9개 역할의 CLI와 새 stdio 응답을 각각 확인했습니다.
